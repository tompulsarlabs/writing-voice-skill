# Project instructions

Maintain `writing-voice-custom/` as the source of the writing skill. Keep the
skill and its evaluation criteria consistent; preserve meaning and uncertainty
when changing style rules. Run the skill validator and exercise any changed
installer code. Report structural checks separately from model evaluations.

Use `scripts/install.py` for local or repository installations. Keep installation
status and verification evidence in `HANDOFF.md`. Do not place machine paths,
private drafts, credentials, or account identifiers in this public repository.
